第 02 章把「膝要 90 N·m」算成了一个数，这一章看这个数能不能被一台真机器持续交付。读完你能给关节选电机与驱动器、画出它的转矩—转速包络并判断工作点是否越界，也能说清电源、总线与算力为什么是同一个设计问题的四个面。

从电池到地面：一条只剩六成的链

这一节解决一个问题：膝关节要的 90 N·m 究竟从电池的哪一度电里来，一路上丢了多少。

把人形拆成一条能量链，只有七个环节：电芯 → 电池管理系统（Battery Management System, BMS）→ 48 V 母线 → 三相桥 → 电机 → 减速器 → 关节 → 地面。控制算法再漂亮，最后交付到地面的也只有链末端那一点力矩。每一环都有自己的效率，乘起来才是整机效率。

取一组常见值：电池放电 0.98、BMS 与母线 0.98、三相桥 0.96、电机 0.87、减速器 0.80、轴承与足底滑移 0.92。乘起来是 0.59。也就是说，一个 60 kg 的人形以 1.2 m/s 行走、机械功率约 420 W 时，电池要输出 710 W，其中 290 W 直接变成热。这条链上没有哪一环特别差，差的是它们乘在一起。

三处损耗各有各的物理。电机是铜损 I²R：相电流 40 A、相电阻 0.05 Ω、三相同时导通，就是 240 W，而这台电机额定才 300–500 W，所以铜损是主要热源。减速器是摩擦与搅油：谐波 70–85%，两级行星 90–95%，同一台电机换减速器，连续力矩能差 20%。三相桥是导通加开关：40 A 下每只 MOSFET 约 3 W，六只十几瓦，靠 2 oz 铜箔和铝基板散掉。

热是最终的约束。绕组 120–150 °C、MOSFET 结温 150–175 °C、钕铁硼磁钢 80–120 °C 开始不可逆退磁。于是同一台电机有两个力矩：峰值靠热容，能撑 1–10 s；连续靠热阻，能撑一辈子。两者通常差 2–4 倍，这个比值不是厂家保守，是热阻和热容的比值。

无刷电机与 FOC：把电流变成力矩

这一节解决一个问题：驱动器只有一条 48 V 直流母线，凭什么在电机里造出一个幅值和方向都可控的旋转磁场。

无刷电机的定子有三组绕组，空间上互差 120°；转子是永磁体，p 对极。没有电刷，换相只能由电路完成：先知道转子在哪，再在正确的时刻把电流切到正确的相。

六步换相：便宜，但每 60° 跳一次

最省事的做法是六步换相（six-step commutation）：三个霍尔传感器把一圈分成六个扇区，每个扇区导通两相、悬空一相，每 60° 电角度换一次。电路只要 6 个 MOSFET（金属氧化物半导体场效应管，开关管）和 3 个霍尔传感器，成本最低。代价是电流矢量在空间里跳着走——它只能停在六个方向上，相对 q 轴有 ±30° 的误差，而转矩正比于这个夹角的余弦，于是转矩以 6 倍电频率脉动，峰谷差 1 − cos 30° = 13.4%。低速时你能听见这个频率的嗡嗡声，也能在力传感器上看到它。

FOC：把坐标系搬到转子上

磁场定向控制（Field-Oriented Control, FOC）换了个问法：不去管三相各自该多少安，而是问「相对于转子，电流应该指向哪」。把三相电流投影到一个跟着转子转的坐标系里，产生力矩的分量叫 q 轴电流，只发热不产力矩的叫 d 轴电流。控制器要做的事只剩两件：把 d 轴压到 0，把 q 轴给到目标值。

两步变换。Clarke 变换把三相压成两相静止坐标 αβ，少掉一个自由度（三线无中线，三相电流之和恒为零）：

iα = ia，iβ = (ia + 2ib) / √3 3.1

Park 变换再把 αβ 转到随转子旋转的 dq。这一步是整个 FOC 的关键：变换之后，原本以电频率正弦变化的电流变成了两个直流量，PI 控制器终于可以没有稳态误差地跟踪它。

id = iαcos θe + iβsin θe，iq = −iαsin θe + iβcos θe 3.2

变换完之后，力矩关系简单得不像话：

τ = (3/2)·p·ψf·iq，Kt = τ / iq = (3/2)·p·ψf 3.3

ψf 是永磁体磁链：永磁体穿过一相绕组的磁通量，单位 Wb；p 是磁极对数。三相电流合成后力矩 = (3/2)·p·ψf·iq，3/2 来自等幅值 Clarke 变换；先把它当比例常数 Kt 用也可以。一台 Kt = 0.11 N·m/A 的电机，想要 8 N·m 就下 73 A 的 iq。Kt 不是常数：磁钢温度每升 1 K 约降 0.1–0.2%，80 °C 温升就是 8–16% 的力矩误差。靠电流估力矩的执行器必须做温度补偿，否则机器人热起来之后，同一条腿会「变软」。

电流得先测准。FOC 的前提是知道三相电流。常见做法是三个下桥臂各串一个 0.5–1 mΩ 的分流电阻，在脉冲宽度调制（Pulse-Width Modulation, PWM）周期的中点触发模数转换器（Analog-to-Digital Converter, ADC）——此刻下桥臂导通，相电流全部流过电阻。采样窗口只有 1–2 µs，12 bit ADC、±50 A 量程对应 24 mA 的分辨率。

上下桥臂不能同时导通，必须插死区（dead time），典型 0.5–1 µs。20 kHz 的周期是 50 µs，1 µs 死区占 2%，每个开关周期都带来约 2% 的电压误差。低速小电流时这个误差比 PI 的输出还大，表现为低速转矩脉动和电流过零畸变，工程上按电流方向把死区电压补回去。

最后一步把 (vd, vq) 变回三相占空比。空间矢量脉宽调制（Space-Vector PWM, SVPWM）把 8 个基本矢量拼成一个六边形，线性区能输出的最大相电压是 Vdc/√3，48 V 母线对应 27.7 V。想要更高只能进过调制，波形开始失真、电流谐波上升。

带宽：20 kHz 开关只买到 2 kHz 电流环

fbw ≈ fpwm / 10 3.4

这条经验式来自延迟：采样在周期中点、计算要一个周期、PWM 下一个周期才生效，合起来约 1.5 个开关周期。20 kHz 开关对应 2 kHz 电流环；在 2 kHz 处，75 µs 的延迟已经是 360° × 2000 × 75 µs = 54° 的相位滞后，相位裕度被吃掉一半。所以 20 kHz 的驱动器实际能给的力矩带宽是 1–2 kHz，这也是整条控制链里最快的一环——位置环只能到 1 kHz，感知在 30–100 Hz，规划在 10 Hz。

三相电流按 ia = Imcos θe 生成，合成矢量幅值 1.5·Im、方向 θe。读数用三相直接相加的口径（不乘 2/3），比等幅值 Clarke 大 1.5 倍，力矩比例不变。转子 d 轴画在电流矢量之后 90°，所以 FOC 时 iq 满幅、id≈0；切到六步，id 在正负之间来回摆，那部分电流只发热。id 的另一个用途是弱磁：进入恒功率区后把它给成负值，用定子电流削掉一部分磁链，才能继续升速。

把这套变换写成中断服务程序，一个 20 kHz 的电流环只有二十来行。下面这段是 C++，省略了编码器校准、参数辨识与故障恢复。

// 20 kHz 电流环：一次中断走完 采样 → Clarke → Park → PI → 反 Park → SVPWM
void ADC_Injected_IRQHandler(void) {   // PWM 中点触发，躲开开关噪声
  float ia = read_phase_a();    // 下桥臂 0.5 mΩ 分流电阻，12 bit
  float ib = read_phase_b();
  float ic = -ia - ib;           // 三线无中线：基尔霍夫定律省一路 ADC

  float th = encoder_electrical();  // 机械角 × 极对数，已补 1.5 周期延迟
  float i_alpha = ia;               // Clarke（等幅值，省掉 2/3 系数）
  float i_beta  = (ia + 2.0f * ib) * 0.57735f;

  float c = cosf(th), s = sinf(th);
  float id =  i_alpha * c + i_beta * s;   // Park：搬到随转子旋转的 dq 系
  float iq = -i_alpha * s + i_beta * c;

  float vd = pi_run(&pi_d, 0.0f - id);   // 表贴式电机：id* = 0
  float vq = pi_run(&pi_q, iq_ref - iq);  // iq_ref = tau_ref / Kt
  svpwm(vd * c - vq * s,              // 反 Park 回 αβ
        vd * s + vq * c, vbus());

  if (overcurrent_flag()) pwm_disable();  // 比较器 <100 µs
}

驱动器：电压、电流与热的三个上限

这一节解决一个问题：同一台电机换一块驱动板，峰值力矩可能差一倍；母线电压到底买到了什么。

驱动器只有三个上限：电压、电流、温度。三者谁先到，工作点就被谁卡住，包络的形状就是这三个约束的交集。

电压是第一个上限。13 串锂离子电芯：3.7 V 标称 × 13 = 48.1 V，满电 4.2 × 13 = 54.6 V，放到 3.0 V 截止是 39 V。这个数字刚好压在安全特低电压（Safety Extra-Low Voltage, SELV）60 V 直流边界之下，又能把 2 kW 的功率压在 42 A。24 V 系统同样功率要 83 A，线损是 4 倍；72 V（20 串，满电 84 V）能继续降电流，但越过 60 V 就要按危险电压做绝缘与安规。

电压在电机侧的作用写在电压圆里：电流能灌进去的前提是剩下的电压够抵消电阻压降和反电动势。

(ωeLqiq)² + (R·iq + ωeψf)² ≤ (Vdc/√3)² 3.5

反电动势 ωeψf 随转速线性涨。到了某个转速，它把 Vdc/√3 吃光，电流再也灌不进去——这就是图 3.2 里的拐点。

保留 id 时，两个分量是 R·id − ωeLqiq 与 R·iq + ωeLdid + ωeψf；表贴式电机 Ld = Lq，id 只在平方项里出现，所以代码可以把负 id 写进常数项去扫弱磁。式中的 Lq 是 q 轴电感（H），ωe 是电角速度（rad/s）。

电流与热是第二、第三个上限。MOSFET 的导通损耗是 I²R：2 mΩ 的管子过 40 A 是 3.2 W，六只加起来十几瓦，靠 2 oz 铜箔和铝基板散掉。峰值电流由结温和母线电容纹波决定，通常给到连续的 2–3 倍，持续 1–10 s。控制里必须知道这个时间常数：跌倒恢复用满峰值 300 ms 没问题，连续 5 s 就会触温保，接下来 30 s 机器人只能出连续力矩。

再生制动是最容易被漏掉的一条路径。减速时电机变成发电机，能量往回灌。一条腿的等效惯量按 0.5 kg·m²、从 10 rad/s 停下算，动能 ½Jω² = 25 J。这 25 J 如果全部灌进 1000 µF 的母线电容，电压会从 48 V 抬到 √(48² + 2×25/0.001) = 228 V，电容和 MOSFET 一起炸。所以驱动器必须有回馈通路：要么电池能吸收（BMS 允许充电且不是满电），要么泄放电阻把能量烧掉。行走时膝盖每步都在做负功，回馈是常态而不是意外。

图 3.2 的包络来自一台 9:1 的准直驱（Quasi-Direct Drive, QDD）关节。准直驱的意思是减速比低到能反驱：外力推关节时电机跟着转，腿的反射惯量小、抗冲击，代价是电机必须自己做高扭矩密度。这类关节在常用转速内卡在电流与热上，转速一上去电压圆才接管——这两段的分界就是下面这张图要画的东西。

把三个限界写成代码，就能回答「这个工作点行不行」。下面 25 行在电压圆与电流圆里扫描负 id，返回给定转速下允许的最大 q 轴电流；它假设磁路线性，所以是上界而不是实测值。

# 三条限界取交：电压圆 + 峰值电流 + 连续热限
import math

R, Lq, psi, p, N = 0.040, 55e-6, 0.0105, 7, 9   # 电机与减速器（SI）
VDC, I_PEAK, I_CONT = 48.0, 120.0, 35.0      # 母线、峰值、连续
KT = 1.5 * p * psi                             # N·m/A

def iq_max(omega, vdc=VDC, imax=I_PEAK, steps=240):
    """电压圆与电流圆求交，允许负 id 弱磁，返回最大 iq"""
    we, V = p * N * omega, vdc / math.sqrt(3)  # 电角速度、相电压上限
    A = R * R + (we * Lq) ** 2
    B = 2 * R * we * psi              # id 在 iq 的一次项里恰好消掉
    best = 0.0
    for k in range(steps + 1):
        idc = -imax * k / steps            # 从 0 扫到 -imax
        C = (R * idc) ** 2 + (we * Lq * idc + we * psi) ** 2 - V * V
        disc = B * B - 4 * A * C
        if disc >= 0:
            iq = (-B + math.sqrt(disc)) / (2 * A)
            best = max(best, min(iq, math.sqrt(imax**2 - idc**2)))
    return KT * best * N                  # 折算到关节侧

for tag, tau, v in (("行走 1.2 m/s", 40, 1.2), ("快跑 3.3 m/s", 95, 3.3)):
    w = v / 0.35                            # 腿长 0.35 m 折算关节角速度
    peak, cont = iq_max(w), iq_max(w, imax=I_CONT)
    state = "可持续" if tau <= cont else ("仅峰值" if tau <= peak else "越界")
    print(f"{tag}: w={w:.1f} rad/s 峰值 {peak:.0f} 连续 {cont:.0f} -> {state}")
print(f"H1 膝 360 N·m @ 9.4 rad/s 峰值 {iq_max(9.4):.0f} -> 越界约 3 倍")

这台示例按 35 kg 级整机、行走时膝关节峰值需求 40 N·m 计（不是第 02 章那台 60 kg 参考机体——那里的 88 N·m 是单腿静态值，两者不是同一台机器）。输出是：行走 1.2 m/s 时峰值 119、连续 35 N·m——119 = 0.11 N·m/A × 120 A × 9，35 = 0.11 × 35 A × 9——需求 40 属于「仅峰值」；快跑 3.3 m/s 时需求 95，同样是「仅峰值」；H1 的 360 N·m 在这个包络上越界约 3 倍，所以它必须换更大的电机或更高的母线。第一条结论有点反直觉：走路时膝关节力矩就已经超过连续热限，靠的是占空比——每一步只有 30% 的时间在用力，热在剩下的 70% 里散掉。散热设计算的是均方根，不是峰值。

传感链：精度不在编码器上

这一节解决一个问题：编码器标着 19 bit，为什么末端还是差 2 mm。

分辨率不等于精度。19 bit 是 524288 线，电机端一圈 360°，一格 0.00069°。经 10:1 减速器，关节端的分辨率是：

Δθjoint = 360° / (2N · G) 3.6

代入 N = 19、G = 10，得 6.9×10⁻⁵°，在 0.4 m 的力臂上是 0.48 µm。这个数字比任何机械误差都小三个数量级以上。真正的误差来自别处：背隙（谐波 1–3 arcmin 即 0.017–0.05°，行星 3–10 arcmin）、连杆与减速器的柔度（关节刚度 1×10⁴ N·m/rad，60 N·m 下变形 0.006 rad = 0.34°）、标定与装配（0.2°）、热漂。

结论很直接：想让末端进 1 mm，先解决柔度和标定，再谈编码器。双编码器（电机端加关节端）能同时消掉背隙并测出传动件的扭转变形，是目前高端关节的标配，代价是多一路编码器和一根穿轴线。反过来，如果只装电机端编码器，减速器的背隙就只能靠标定表和负载模型猜。

IMU 的误差分三类，常被混着说。惯性测量单元（Inertial Measurement Unit, IMU）的零偏（bias）是静止时的常数误差，±1 °/s 的量级；噪声密度是白噪声，0.014 °/s/√Hz，100 Hz 带宽下积分成 0.14 °/s 的均方根；温漂是零偏随温度的变化，0.01–0.05 °/s/K。零偏 1 °/s 积分 60 s 就是 60° 的姿态误差，所以 IMU 只能管 10 ms 级的姿态变化，长时间必须靠足底接触与视觉修正（第 08 章）。开机 10 分钟内的温漂比噪声大一个量级，每次上电都要重新标定零偏。

关节力矩有三条路。最便宜的是用电流估力矩：τ = Kt·iq，不需要任何额外传感器，精度 5–10%，误差来自 Kt 温漂和减速器摩擦。应变片贴在关节输出或谐波柔轮上，全桥输出 1–2 mV/V，配 24 bit ADC 能做到 0.1% 满量程，约 0.1 N·m。串联弹性执行器（Series Elastic Actuator, SEA）在电机和负载之间串一根弹簧，用编码器测弹簧变形算力矩，抗冲击最好，但弹簧谐振把力控带宽压到 20–50 Hz。选型判据：要带宽和背驱（腿）用电流估计或应变片，要力控精度和抗冲击（协作臂、脚踝）用 SEA。

足底六维力是接触状态最可靠的一路。它装在脚踝和手腕，量程 ±145 N / ±5 N·m、分辨率 1/16 N·m（ATI Mini45 一级，力矩通道）。它给出力与力矩，压力中心（Center of Pressure, CoP）由 p = M/F 算出：Fz = 400 N 时，1/16 N·m 的力矩分辨率对应 0.0625 / 400 = 0.16 mm 的 CoP 分辨率，比编码器推出来的关节位置还细。它比用正向运动学推出来的位置更可信，也是第 08 章零速修正的输入。

视觉（RGB-D，30–90 fps，1 m 处深度噪声 1–2 cm）负责「在哪、抓什么」；事件相机用 µs 级延迟和 120 dB 动态范围补高速运动；触觉阵列（1–5 mm 空间分辨率、0.1–1 N）负责滑移检测。它们都不进 1 kHz 环。

电源：为什么是 48 V

这一节解决一个问题：为什么几乎所有电动人形都选 48 V，以及一块 720 Wh 的电池能撑多久。

48 V 买的是电流。P = VI，同样 2 kW，48 V 要 42 A，24 V 要 83 A。线损按 I²R 走：4 mm² 铜线每米 4.3 mΩ，走 3 m（来回 6 m），42 A 时 45 W，83 A 时 176 W。24 V 系统光在线束上就多烧 130 W，还要多背两公斤铜。这是 48 V 成为事实标准的第一个原因；第二个是它刚好卡在 SELV 边界内，第三个是 3.7 V 的电芯正好整除：13 串就是 48 V，不需要任何非标串数。

代价是安全边界。48 V 标称听起来温和，满电 54.6 V 已经贴着 SELV 的 60 V 上限；16 串的 H1 满电 67.2 V 直接越界。母线电容 1000 µF 储 1.5 J，足够把掉在端子上的扳手烧出坑。

串数与容量决定能跑多久。13 串是最常见的配置。电芯用 21700（4.8 Ah），3 并就是 14.4 Ah × 48 V ≈ 690 Wh；H1 的 0.864 kWh / 15 Ah 是同一量级。容量不是越大越好：电池占整机质量 15–25%，多带 1 kWh 就多 5 kg，腿的力矩预算立刻变紧。续航粗算把机械功率除以链效率，再加上电子功耗：

P ≈ CoT·m·g·v / η + Pelec，t = E / P 3.7

CoT 是第 01 章定义的运输代价：单位质量单位距离消耗的无量纲能量。人的步行 CoT 约 0.2，人形机器人 0.5–1.0；取 CoT = 1 就退化成 m·g·v/η，那是「一直在爬坡」的上界，会把续航估低一半。算例：60 kg、1.2 m/s、CoT = 0.6，机械功率 424 W；除以 0.59 得 719 W；加 80 W 电子功耗，约 800 W。720 Wh 撑 54 分钟。站着不动只有 150 W（保持力矩加计算），能撑 4.8 小时。续航对任务剖面的敏感度是 5 倍，所以「续航两小时」这种说法必须带速度与负载才有意义。

BMS 管三件事：单体电压 3.0–4.2 V、被动均衡 50 mA 级、总电流 100 A 级。它也是整机唯一一块「必须一直活着」的板子——BMS 挂了、接触器不断开，电池就会被过放到 0 V，那组电芯直接报废。

预充：母线电容 1000 µF，直接合闸时浪涌只受线路电感与等效串联电阻限制，峰值可达 10²–10³ A，接触器触点会粘连。串一个 50 Ω 电阻，时间常数 τ = RC = 50 ms，5τ = 250 ms 充到 99%，浪涌被压到 1.1 A。所以上电顺序永远是：预充 → 检测母线电压超过 90% → 旁路接触器闭合 → 断开预充。

泄放：急停或下电后，母线电容上的 1.5 J 必须放掉。泄放电阻按 τ = 10 ms 设计，30 ms 内降到 12 V 以下。它同时兼作回馈泄放，功率按峰值回馈算——一条腿 25 J 在 0.1 s 内释放就是 250 W 量级。

警告 Warning

48 V 不是安全电压。16 串满电 67.2 V 已越过 SELV 的 60 V 边界，湿手接触两端就可能通过人体形成回路；更常见的事故是母线电容——泄放回路一旦失效，断电几分钟后仍有 50 V 以上残压，1.5 J 集中在接触点上足够焊出一小块熔痕，再引发一串短路。维修前先量母线，别信「已经关了」。

算力与总线：谁在什么时候说话

这一节解决一个问题：为什么一台人形要同时装 MCU 和 SoC，30 个关节又怎么在 1 ms 内收到同一条指令。

两个时间尺度，两种芯片。微控制器（Microcontroller Unit, MCU）跑硬实时。STM32H7 一级：480 MHz Cortex-M7、1 MB RAM、带 FPU 和硬件除法。一个 20 kHz 电流环（采样、Clarke/Park、PI、SVPWM）约 2–4 µs，单核能带 4–8 个关节；1 kHz 的关节环（位置、力矩、温度、保护）再占 20–30%。它不能跑 Linux——一次调度抖动 100 µs 就够毁掉电流环。

片上系统（System on Chip, SoC）跑感知与策略。Jetson Orin NX 117 TOPS 在 10–40 W，AGX Orin 275 TOPS 在 15–60 W。它跑 Linux，做 30–100 Hz 的视觉和 10–50 Hz 的策略网络。40 W 的芯片靠自然对流散不掉，得配风扇或热管——这是很多人形背部鼓一块的原因。两者的接口只有一条：SoC 把 (qd, τff, Kp, Kd) 通过以太网或 CAN 发给 MCU，MCU 保证 1 ms 内执行。分层不是架构洁癖，是延迟预算逼出来的。

总线要在 1 ms 内把指令送到 30 个关节。先看四种候选的硬指标，再看谁适合做整机同步。

CAN FD 数据段 5 Mbit/s，一帧 64 B 连仲裁带 CRC 约 130–150 µs。30 个关节、每帧 8 B 状态加 8 B 指令，一条总线在 1 ms 内只能塞 6–7 帧，所以整机要么开 4–6 条 CAN，要么换 EtherCAT。EtherCAT 100 Mbit/s，一帧穿过所有从站，30 个关节的过程数据在 100 µs 内走完，分布式时钟（Distributed Clock, DC）把各节点的时间对齐到 1 µs 以内。代价是从站要专用芯片（ET1100、LAN9252），每条支路只能菊花链或环网，断一处整段掉线；CAN FD 便宜、能随便分支，但没有全局时钟，节点间抖动 10–100 µs，做不了多关节同步的力分配。

线束与接地是最后一道，也是最容易翻车的一道。三相电机线是 dv/dt 5–10 kV/µs 的干扰源，编码器线是 mV 级的信号，两者必须分槽走、交叉处正交。屏蔽层单端接地（驱动端），双端接地会形成地环流，把编码器计数打飞。48 V 功率地与信号地星型单点汇合，接地电阻小于 0.1 Ω。线束占整机质量 5–8%，却是现场故障的第一大来源。

工程经验 Field Note

编码器偶发跳数、一加电流就报位置错误，九成不是固件 bug：电机线与编码器线绑在同一束，共模干扰直接进了差分对。把两束线分开 50 mm、编码器线换双绞屏蔽、屏蔽层只在驱动板一端接地，问题通常当场消失。先怀疑线束，再怀疑代码。

可靠性与安全：故障树上的四个断点

这一节解决一个问题：控制器死了、总线断了、有人拍下急停，机器应该怎么失效。

安全的定义不是「不出故障」，而是「故障时后果可预测」。硬件上要回答四个问题。

第一个问题是：谁发现控制器死了。独立看门狗由内部 RC 振荡器驱动，1 ms 内不喂就复位。但复位本身不解决问题——腿会因为失去力矩而自由下落。所以通信超时（2 ms 收不到指令）触发的动作是力矩斜坡归零并切入阻尼，而不是硬断。硬断只留给急停与安全转矩关断。

第二个问题是：怎么切断能量。安全转矩关断（Safe Torque Off, STO）按 IEC 61800-5-2 实现：双通道切断栅极驱动，保留逻辑电，响应小于 10 ms。它和「断母线」的区别是，断母线后电容还有残压、电机可能反电动势回灌，重新上电还要重新预充；STO 只关功率级，恢复快，母线不失电。急停链是双回路 24 V，串联所有急停按钮、碰撞开关与无线急停接收器，任一断开就同时触发主接触器与 STO。单点故障不能导致失效：一个回路断线另一个还能动作，一个接触器粘连另一个还能断开。

剩下两件是 EMC 与绝缘。电磁兼容（Electromagnetic Compatibility, EMC）按 IEC 61800-3 的 C2/C3 做：电机线加共模扼流，Y 电容漏电流小于 3.5 mA，30–230 MHz 段的辐射发射压在 IEC 61800-3 的 C2 限值以下。48 V 系统不需要加强绝缘，但电机绕组对壳要过 500 VDC 耐压，绝缘电阻大于 10 MΩ。故障树上有四个单点：BMS 主接触器、EtherCAT 主站、急停回路、单编码器。前三个要么冗余要么失效安全，第四个的解法是双编码器，或者约定「编码器失效即切阻尼」。把这张表画出来，比在代码里加一百个 if 有用。

三个真实系统怎么做的

这一节解决一个问题：把前面的数字放到真实机器上对照，看设计者在哪里做了不同的取舍。

Unitree H1 用电压换速度。它的膝关节标称 360 N·m，按模组质量折算 189 N·m/kg，母线最高 67.2 V（16 串），电池 0.864 kWh。360 N·m 对一台 47 kg 级的机身是 7.7 N·m/kg 体重，这个比值决定了它能做多大的动态动作而不先让关节饱和。16 串不是随便选的：同样一台电机，母线从 48 V 提到 67.2 V，恒转矩区延长 40%，代价是整机失去 SELV 资格，绝缘、爬电距离、连接器都要重做。

MIT Humanoid 换掉的是力矩传感器。它用 6:1 行星加减速，膝关节再加一级 2:1 皮带做到 12:1；髋用 U10 模块（33.6 N·m / 619 g），膝用 U12（68 N·m / 1.17 kg），经皮带放大到峰值 136 N·m（68 × 2），电源 60 V / 3 Ah。它不装关节力矩传感器，靠电流估力矩，靠低惯量腿吸收冲击。这是一条明确的技术路线：用带宽和背驱换掉传感器与弹性件，代价是力矩精度依赖 Kt 标定与摩擦模型，减速器背隙必须小。180 Wh 的电池只够几分钟剧烈运动，说明它是研究平台而不是产品。

Optimus 换的是整机架构。特斯拉把 48 V 定为整机唯一的功率域，电池、关节与计算共用一条母线（公开演示）。这个决定省掉的是一级大功率 DC/DC：2 kW 下按 95% 效率算就是 100 W 的额外热源，还要多一套线束与保护。代价是所有外设都要按 48 V 重新设计，包括那些原本只做 12 V 的传感器。三条路线放在一起看，分歧不在电机，而在「用什么换什么」：H1 用电压换速度，MIT 用带宽换传感器，Optimus 用架构统一换热管理与线束。

本章要点 Takeaways

  1. 整链效率约 59%。要 100 W 机械功率，电池得掏 170 W，剩下 70 W 全是热；峰值与连续力矩差 2–4 倍，是热容与热阻的比值，不是厂家保守。
  2. FOC 的全部工作是把电流矢量钉在 q 轴上。20 kHz 开关只买到 1–2 kHz 电流环带宽，因为采样与计算延迟按 1.5 个开关周期收税；六步换相省下的电路，要用 13.4% 的转矩脉动来还。
  3. 精度瓶颈不在编码器。19 bit 折算到末端只有 0.5 µm，背隙 0.35 mm、柔度 2.4 mm，差 3.7 个量级；先提刚度、先做标定。
  4. 48 V 标称不等于安全。16 串满电 67.2 V 已越过 SELV 的 60 V，25 J 的回馈能把 1000 µF 母线顶到 228 V，所以预充、泄放、STO 是电路的一部分，不是附件。
